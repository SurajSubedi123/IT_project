# IT Simulation Project - React Login & Sign Up

This project contains the pixel-perfect React implementation of the **IT SIMULATION PROJECT** Login and Sign Up interface, alongside the Home dashboard view.

## 🚀 Features

- **Exact Match Design**:
  - Top Navy Header: `IT SIMULATION PROJECT / Login and Sign Up`
  - Two-Column Layout:
    - **Welcome Back (Login)**:
      - Email address & password fields with signature light slate tint (`#f1f5f9`).
      - Blue **Log In** button (`#2563eb`).
      - **New student? Create an account →** link that auto-scrolls/focuses the signup form.
    - **Create Student Account (Sign Up)**:
      - Full name, Student email, Password, and Confirm password fields with exact placeholders.
      - Full-width emerald green **Sign Up** button (`#15803d`).
- **Interactive State & Validation**:
  - Live client-side email format validation.
  - Password match check and minimum length rules.
  - Optional unobtrusive password visibility toggle (Eye / EyeOff).
  - Success and error feedback messages.
- **Home Page View (Image 2)**:
  - Integrated full Home dashboard with welcome announcement, "How it works", "Training areas", and "Before you begin" cards.
  - Easily toggle between views via the header controls.
- **Fully Responsive**:
  - Flawless experience on desktop, tablet, and mobile screens.

## 🛠️ Getting Started

To run the development server:

```bash
npm run dev
```

To build for production:

```bash
npm run build
```

To preview the production build:

```bash
npm run preview
```
